# Changelog

All releases are ad-hoc signed and not notarized. See the README's Gatekeeper
instructions before the first launch.

## v1.3 — 2026-08-20

Added DuckDuckGo as a browser choice, with a private option on supported builds.

- Choose ordinary or private DuckDuckGo from the same chooser.
- Private mode uses isolated disposable state, needs no browser extension or
  Accessibility permission, and is limited to supported official
  direct-download builds.

## v1.2 — 2026-08-18

Added Google Chrome Beta as a separate browser, with its own profiles and
normal or private choices.

## v1.1 — 2026-08-14

Added per-link mail app selection for `mailto:` links.

- Pick from installed mail apps and manage their order in Mail Settings.
- PickVia does not preview or save recipients, subjects, message bodies, or the
  original mail link.

## v1.0 — 2026-08-14

First public release, packaged as a drag-to-Applications DMG.

- Choose a browser, profile, or supported private mode for each web link.
- Supports Safari, Chrome, Chromium, Edge, Brave, Vivaldi, and Firefox on
  macOS 14 or later.
