<p align="center"><strong>Пусть ссылки открываются в нужном браузере или профиле.</strong></p>

macOS может использовать не то окно или профиль браузера, а все ссылки `mailto:`
отправляет в одно заданное почтовое приложение по умолчанию. PickVia спрашивает,
где открыть каждую ссылку, чтобы вы могли выбрать нужный профиль браузера или
установленное почтовое приложение.

**[Посетите сайт PickVia](https://kiteretsu903.github.io/pick-via/)**, чтобы увидеть
снимки экрана, основные изменения выпусков и [журнал изменений](https://kiteretsu903.github.io/pick-via/changelog.html).

- **Выбор браузера или профиля для каждой веб-ссылки.**

- **Локальная обработка ссылок без сохранения истории их открытия.**

## Установка

1. Скачайте и откройте `PickVia-v1.5.1.dmg` со страницы
   [выпуска на GitHub](https://github.com/kiteretsu903/pick-via/releases/latest).
2. Перетащите **PickVia** в папку **Программы**, показанную в установщике.
3. Откройте **PickVia** из папки «Программы» и следуйте инструкциям приветствия.
4. Выберите **Сделать по умолчанию**. macOS отдельно запросит
   разрешения на обработку ссылок HTTP и HTTPS.
5. При желании проверьте установленные почтовые приложения и сделайте PickVia
   обработчиком ссылок `mailto:` по умолчанию или выберите **Пропустить настройку почты**.

### Первый запуск и Gatekeeper

PickVia v1.5.1 подписан сертификатом Apple Development и не прошёл нотариализацию Apple. macOS может
заблокировать первый запуск скачанного приложения. Если вы скачали его со страницы
выпуска на GitHub и решили доверять ему:

1. Попробуйте открыть PickVia один раз и закройте предупреждение.
2. Откройте **Системные настройки → Конфиденциальность и безопасность** и
   прокрутите до раздела **Безопасность**.
3. Нажмите **Всё равно открыть**, затем подтвердите **Открыть**. Кнопка доступна
   примерно в течение одного часа после заблокированной попытки запуска.

Если кнопка **Всё равно открыть** недоступна, убедитесь, что **PickVia.app**
находится в папке «Программы», повторите заблокированный запуск один раз и выполните:

```zsh
xattr -dr com.apple.quarantine "/Applications/PickVia.app"
```

Apple описывает этот способ обхода Gatekeeper и его последствия для безопасности
в статье [Безопасное открытие приложений на Mac](https://support.apple.com/en-asia/102445).

## Поддержка браузеров

| Браузер / редакции | Профили | Обычное окно | Приватное окно |
|---|---:|---:|---:|
| Safari | Экспериментально | Да | Нет |
| Safari Technology Preview | Нет | Да | Нет |
| DuckDuckGo | Нет | Да | Да* |
| Chrome Stable / Beta / Dev / Canary, Chromium | Да | Да | Да |
| Edge Stable / Beta / Dev / Canary | Да | Да | Да |
| Brave Stable / Beta / Nightly | Да | Да | Да |
| Vivaldi Stable / Snapshot | Да | Да | Да |
| Firefox Stable / Developer Edition / Nightly | Да | Да | Да |
| Opera, Arc, Orion | Нет | Да | Нет |

\* DuckDuckGo Private использует изолированные одноразовые данные в совместимых
сборках без песочницы, без ограничения версии. Для него не нужны
ни расширение DuckDuckGo, ни разрешение универсального доступа. Обычные ссылки
DuckDuckGo не требуют определённой версии или подписи издателя. Приватные данные
удаляются после завершения процесса браузера, если PickVia работает, либо при
последующем запуске PickVia или открытии ссылки через него.

Каждая установленная редакция отображается как отдельный браузер со своим именем
и значком. Профили Firefox, связанные с другой установленной редакцией, исключаются
из списка профилей этого браузера. Привязка определяется по пути приложения,
записанному Firefox. Для профилей с отсутствующими или неизвестными метаданными
сохраняется прежний резервный способ обработки: они могут отображаться в нескольких
редакциях.

Варианты «По умолчанию» на уровне браузера работают без доступа к профилям;
предоставление доступа добавляет найденные профили. Приватные окна выбираются
на уровне браузера: сочетание конкретного профиля и приватного режима не
поддерживается. Opera, Arc и Orion сейчас поддерживают только обычное открытие
на уровне приложения.

Поддержка зависит от версии браузера и состояния запуска.

## Профили Safari (экспериментальная функция)

Включите профили Safari Stable в настройках браузеров. Эта функция включается
по желанию и требует разрешений универсального доступа («Управление устройством
и доступ к данным» в macOS 27 или новее) и автоматизации. Каждая ссылка открывается
в новом окне выбранного профиля. Открытие ссылок в профилях Safari остаётся
экспериментальной функцией.

Для локальных сборок задайте в `PICKVIA_SIGNING_IDENTITY` отпечаток сертификата
подписи кода или сохраните его в игнорируемом файле `.signing-identity`, затем
запустите `scripts/build-app.sh`. Используйте один и тот же сертификат при повторных
сборках, чтобы сохранить идентичность приложения для разрешений macOS.

## Поддержка почты

PickVia обрабатывает только ссылки `mailto:`. Он находит установленные приложения,
зарегистрированные в macOS для почтовых ссылок, и предлагает выбор на уровне
приложения — без выбора учётной записи, профиля, личности отправителя или режима
создания письма. В настройках почты можно включать, отключать, упорядочивать и
повторно находить зарегистрированные обработчики; настройка почты при первом
запуске остаётся необязательной.

## Конфиденциальность

- Открываемые URL обрабатываются локально; PickVia никогда не передаёт, не
  записывает в журнал и не сохраняет их.
- PickVia не обращается к истории браузера, файлам cookie, сеансам, сохранённым
  паролям или содержимому страниц.
- Окно выбора почтового приложения не показывает предварительный просмотр,
  не записывает в журнал и не сохраняет получателей, темы, текст сообщений
  или исходный запрос `mailto:`.

Отозвать доступ к профилям можно в **Настройки браузеров → Доступ к профилям → Удалить доступ**.

См. полную [Политику конфиденциальности](https://kiteretsu903.github.io/pick-via/privacy.html).
