# PickVia v1.5

PickVia now supports 80 app and website languages, with 12 README translations. Select a language in Settings or follow your primary system language, with right-to-left layouts where appropriate.

- **Safari profiles, experimentally:** enable Safari Stable profiles in Browser Settings. With Accessibility and Automation permissions, each link opens in a new window of the selected profile. On macOS 27 or later, Accessibility is named Device Control and Data Access.
- **Simpler DuckDuckGo private routing:** improve disposable-session recovery and cleanup, with private support for compatible unsandboxed 1.203.x builds. Normal DuckDuckGo links no longer require a particular version or publisher signature.
- **Consistent app identity:** builds use a fixed signing certificate so rebuilding with the same identity preserves macOS permission identity.

Requires macOS 14 or later on Apple Silicon. This download is signed with an Apple Development certificate and is not notarized. Follow the [README installation instructions](https://github.com/kiteretsu903/pick-via#install) if macOS blocks the first launch.
