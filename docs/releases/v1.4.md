# PickVia v1.4

PickVia now offers more browser editions as separate choices, and groups Firefox profiles under their associated edition when Firefox's metadata identifies it.

- Add Chrome Dev and Canary; Edge Beta, Dev, and Canary; Brave Beta and Nightly; Vivaldi Snapshot; and Firefox Developer Edition and Nightly.
- Add normal app-level routing for Opera, Arc, Orion, and Safari Technology Preview.
- Remove detected Firefox profile duplicates belonging to another installed edition when rescanning. Renamed profiles still associate by Firefox's recorded app path; profiles with unknown association retain the existing fallback.
- Fix Firefox profile launch paths that macOS temporary-path normalization could incorrectly reject.
- Keep browser-level private windows separate from normal profile routes. Profile-specific private mode is not supported; unavailable route combinations are not offered.
- Refresh README and website screenshots using the current native UI and synthetic data.

Requires macOS 14 or later on Apple Silicon. The app is ad-hoc signed and is not notarized; see the README's existing Gatekeeper installation steps.
