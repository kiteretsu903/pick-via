เวอร์ชัน 1.5

แอปและเว็บไซต์รองรับ 80 ภาษา พร้อม README ฉบับแปล 12 ภาษา เลือกภาษาของคุณได้ในการตั้งค่า

  • ลองใช้ฟีเจอร์โปรไฟล์แบบทดลองของ Safari Stable โดยให้สิทธิ์การช่วยการเข้าถึงและการทำงานอัตโนมัติ แต่ละลิงก์จะเปิดในหน้าต่างใหม่ของโปรไฟล์ที่เลือก
  • ปรับการกู้คืนและล้างข้อมูลเซสชันส่วนตัวของ DuckDuckGo ให้ง่ายขึ้น บิลด์ 1.203.x ที่เข้ากันได้และไม่ใช้แซนด์บ็อกซ์รองรับการส่งลิงก์ไปยังโหมดส่วนตัว ส่วนลิงก์ปกติไม่มีข้อกำหนดเรื่องเวอร์ชันหรือลายเซ็นดิจิทัลของผู้เผยแพร่
  • ใช้ใบรับรอง Apple Development ใบเดิมในการสร้างบิลด์ ไฟล์ดาวน์โหลดไม่ได้ผ่านกระบวนการรับรอง notarization ของ Apple โปรดทำตามคำแนะนำการติดตั้งใน README

เวอร์ชัน 1.4

เลือกเบราว์เซอร์และรุ่นย่อยได้มากขึ้น โดยโปรไฟล์ Firefox จัดกลุ่มตามรุ่นย่อยที่สัมพันธ์กัน

  • เพิ่ม Chrome Dev และ Canary; Edge Beta, Dev และ Canary; Brave Beta และ Nightly; Vivaldi Snapshot; และ Firefox Developer Edition และ Nightly เป็นตัวเลือกเบราว์เซอร์แยกกัน
  • เพิ่มการเปิดลิงก์แบบปกติในระดับแอปสำหรับ Opera, Arc, Orion และ Safari Technology Preview
  • เก็บโปรไฟล์ Firefox ไว้กับรุ่นย่อยที่บันทึกไว้เมื่อระบุได้ และลบรายการซ้ำเดิมที่ตรวจพบเมื่อค้นหาใหม่ โปรไฟล์ที่ไม่มีข้อมูลเมตาความสัมพันธ์ที่เชื่อถือได้ยังคงใช้พฤติกรรมสำรองเดิม
  • แก้ไขเส้นทางโปรไฟล์ Firefox ที่ถูกปฏิเสธหลังจากปรับรูปแบบเส้นทางชั่วคราวของ macOS ให้เป็นมาตรฐาน
  • แสดงเฉพาะรูปแบบการเปิดลิงก์ที่รองรับ หน้าต่างส่วนตัวยังคงเป็นตัวเลือกระดับเบราว์เซอร์ ไม่สามารถใช้โหมดส่วนตัวกับโปรไฟล์เฉพาะได้
