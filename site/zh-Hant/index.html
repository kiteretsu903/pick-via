01 / 開啟前先選擇

合適的瀏覽器。
合適的設定檔。

為每個網頁或電子郵件連結選擇合適的目的地。

01

連結與設定檔，恰當配對。

選擇已啟用的瀏覽器或設定檔，或支援的瀏覽器層級私密視窗。

02

郵件連結，交給合適的應用程式。

選擇你想用的已註冊郵件應用程式，不必讓每個 mailto: 連結都交給同一個預設程式。

03

快速選擇，不打斷步調。

排好常用選項的順序，再按一下或使用鍵盤快速鍵即可。

04

也能選擇瀏覽器版本。

選擇獨立的 Chrome 與 Edge 版本、Brave Beta 或 Nightly、Vivaldi Snapshot，以及 Firefox Developer Edition 或 Nightly。已知版本關聯的 Firefox 設定檔會保留在該版本之下。

05

更多瀏覽器可供選擇。

Opera、Arc、Orion 與 Safari Technology Preview 提供一般瀏覽器選項。設定檔與私密視窗的支援程度依瀏覽器而異。查看瀏覽器支援 →

02 / 選擇郵件應用程式

郵件連結，
交給合適的應用程式。

macOS 通常會將 mailto: 連結交給同一個預設應用程式。PickVia 讓你每次都能從 Mac 上已註冊的郵件應用程式中選擇。

◌
以隱私權為設計原則PickVia 會將原始請求直接交給你選擇的程式，不會記錄或永久儲存郵件內容。

03 / 設定你的選項

一次設定。
快速選擇。

一次設定常用的瀏覽器設定檔與郵件應用程式，再將最常使用的目標重新排序。
