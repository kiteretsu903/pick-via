06 ಸೆಪ್ಟೆಂಬರ್ 2026ಪ್ರಸ್ತುತ ಬಿಡುಗಡೆ

ಆವೃತ್ತಿ 1.5

ಆಪ್ ಮತ್ತು ವೆಬ್‌ಸೈಟ್ 80 ಭಾಷೆಗಳಲ್ಲಿ ಲಭ್ಯವಿದ್ದು, README ಯ 12 ಅನುವಾದಗಳೂ ಇವೆ. ಸೆಟ್ಟಿಂಗ್‌ಗಳಲ್ಲಿ ನಿಮ್ಮ ಭಾಷೆಯನ್ನು ಆಯ್ಕೆಮಾಡಿ.

  • ಪ್ರವೇಶಸಾಧ್ಯತೆ ಮತ್ತು ಸ್ವಯಂಚಾಲನೆ ಅನುಮತಿಗಳೊಂದಿಗೆ ಪ್ರಾಯೋಗಿಕ Safari Stable ಪ್ರೊಫೈಲ್‌ಗಳನ್ನು ಪ್ರಯತ್ನಿಸಿ. ಪ್ರತಿಯೊಂದು ಲಿಂಕ್ ಆಯ್ಕೆಮಾಡಿದ ಪ್ರೊಫೈಲ್‌ನ ಹೊಸ ವಿಂಡೋದಲ್ಲಿ ತೆರೆಯುತ್ತದೆ.
  • DuckDuckGo ಖಾಸಗಿ ಸೆಷನ್‌ಗಳ ಮರುಸ್ಥಾಪನೆ ಮತ್ತು ಸ್ವಚ್ಛಗೊಳಿಸುವಿಕೆಯನ್ನು ಸರಳಗೊಳಿಸಲಾಗಿದೆ. ಸ್ಯಾಂಡ್‌ಬಾಕ್ಸ್ ಇಲ್ಲದ ಹೊಂದಾಣಿಕೆಯ 1.203.x ಬಿಲ್ಡ್‌ಗಳು ಖಾಸಗಿ ಮೋಡ್‌ನಲ್ಲಿ ಲಿಂಕ್ ತೆರೆಯುವುದನ್ನು ಬೆಂಬಲಿಸುತ್ತವೆ; ಸಾಮಾನ್ಯ ಲಿಂಕ್‌ಗಳಿಗೆ ನಿರ್ದಿಷ್ಟ ಆವೃತ್ತಿ ಅಥವಾ ಪ್ರಕಾಶಕರ ಸಹಿಯ ಅವಶ್ಯಕತೆ ಇಲ್ಲ.
  • ಬಿಲ್ಡ್‌ಗಳಿಗೆ ಸ್ಥಿರವಾದ Apple Development ಪ್ರಮಾಣಪತ್ರವನ್ನು ಬಳಸಲಾಗುತ್ತದೆ. ಡೌನ್‌ಲೋಡ್ ನೋಟರೀಕರಿಸಲ್ಪಟ್ಟಿಲ್ಲ; README ಯಲ್ಲಿರುವ ಅನುಸ್ಥಾಪನಾ ಸೂಚನೆಗಳನ್ನು ಅನುಸರಿಸಿ.

06 ಸೆಪ್ಟೆಂಬರ್ 2026

ಆವೃತ್ತಿ 1.4

ಹೆಚ್ಚಿನ ಬ್ರೌಸರ್‌ಗಳು ಮತ್ತು ಆವೃತ್ತಿಗಳನ್ನು ಆಯ್ಕೆಮಾಡಿ; Firefox ಪ್ರೊಫೈಲ್‌ಗಳು ಅವುಗಳಿಗೆ ಸಂಬಂಧಿಸಿದ ಆವೃತ್ತಿಯ ಅಡಿಯಲ್ಲಿ ಗುಂಪುಗೊಂಡಿವೆ.

  • Chrome Dev ಮತ್ತು Canary; Edge Beta, Dev ಮತ್ತು Canary; Brave Beta ಮತ್ತು Nightly; Vivaldi Snapshot; ಹಾಗೂ Firefox Developer Edition ಮತ್ತು Nightly ಅನ್ನು ಪ್ರತ್ಯೇಕ ಬ್ರೌಸರ್ ಆಯ್ಕೆಗಳಾಗಿ ಸೇರಿಸಲಾಗಿದೆ.
  • Opera, Arc, Orion ಮತ್ತು Safari Technology Preview ಗೆ ಆಪ್ ಮಟ್ಟದ ಸಾಮಾನ್ಯ ಮಾರ್ಗನಿರ್ದೇಶನ ಸೇರಿಸಲಾಗಿದೆ.
  • Firefox ಪ್ರೊಫೈಲ್‌ಗಳಿಗೆ ದಾಖಲಾಗಿರುವ ಆವೃತ್ತಿಯನ್ನು ಗುರುತಿಸಲು ಸಾಧ್ಯವಾದಾಗ ಅವುಗಳನ್ನು ಅದೇ ಆವೃತ್ತಿಯೊಂದಿಗೆ ಉಳಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಮತ್ತೆ ಸ್ಕ್ಯಾನ್ ಮಾಡುವಾಗ ಹಳೆಯ ಪತ್ತೆಯಾದ ನಕಲುಗಳನ್ನು ತೆಗೆದುಹಾಕಲಾಗುತ್ತದೆ. ವಿಶ್ವಾಸಾರ್ಹ ಸಂಬಂಧದ ಮೆಟಾಡೇಟಾ ಇಲ್ಲದ ಪ್ರೊಫೈಲ್‌ಗಳಿಗೆ ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಪರ್ಯಾಯ ವಿಧಾನ ಉಳಿಯುತ್ತದೆ.
  • macOS ತಾತ್ಕಾಲಿಕ ಪಥಗಳನ್ನು ಸಾಮಾನ್ಯೀಕರಿಸಿದ ನಂತರ ತಿರಸ್ಕರಿಸಲ್ಪಟ್ಟ Firefox ಪ್ರೊಫೈಲ್ ಪಥಗಳನ್ನು ಸರಿಪಡಿಸಲಾಗಿದೆ.
  • ಬೆಂಬಲಿತ ಮಾರ್ಗ ಸಂಯೋಜನೆಗಳನ್ನು ಮಾತ್ರ ತೋರಿಸಲಾಗುತ್ತದೆ. ಖಾಸಗಿ ವಿಂಡೋಗಳು ಬ್ರೌಸರ್ ಮಟ್ಟದ ಆಯ್ಕೆಗಳಾಗಿಯೇ ಉಳಿಯುತ್ತವೆ; ಪ್ರೊಫೈಲ್-ನಿರ್ದಿಷ್ಟ ಖಾಸಗಿ ಮೋಡ್ ಲಭ್ಯವಿಲ್ಲ.

ಆವೃತ್ತಿ 1.3

  • ಒಂದೇ ಆಯ್ಕೆ ಫಲಕದಿಂದ ಸಾಮಾನ್ಯ ಅಥವಾ ಖಾಸಗಿ DuckDuckGo ಆಯ್ಕೆಮಾಡಿ.
