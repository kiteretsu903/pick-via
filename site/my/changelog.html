06 စက်တင်ဘာ 2026လက်ရှိထုတ်ဝေမှု

ဗားရှင်း 1.5

အက်ပ်နှင့် ဝဘ်ဆိုက်ကို ဘာသာစကား 80 ဖြင့် အသုံးပြုနိုင်ပြီး README ဘာသာပြန် 12 မျိုးလည်း ရှိသည်။ ဆက်တင်များတွင် သင့်ဘာသာစကားကို ရွေးချယ်ပါ။

  • သုံးစွဲနိုင်မှုနှင့် အလိုအလျောက်လုပ်ဆောင်မှု ခွင့်ပြုချက်များဖြင့် စမ်းသပ်ဆဲ Safari Stable ပရိုဖိုင်များကို အသုံးပြုကြည့်ပါ။ လင့်ခ်တစ်ခုစီသည် ရွေးချယ်ထားသော ပရိုဖိုင်၏ ဝင်းဒိုးအသစ်တွင် ပွင့်မည်။
  • DuckDuckGo သီးသန့်ဆက်ရှင်များ ပြန်လည်ရယူခြင်းနှင့် ရှင်းလင်းခြင်းကို ပိုမိုရိုးရှင်းစေထားသည်။ ကိုက်ညီမှုရှိသော sandbox မသုံးသည့် 1.203.x build များသည် သီးသန့်မုဒ်ဖြင့် လင့်ခ်ဖွင့်ခြင်းကို ပံ့ပိုးသည်။ ပုံမှန်လင့်ခ်များအတွက် သီးခြားဗားရှင်း သို့မဟုတ် ထုတ်ဝေသူလက်မှတ် မလိုအပ်ပါ။
  • Build များအတွက် တူညီသော Apple Development အသိအမှတ်ပြုလက်မှတ်ကို အသုံးပြုသည်။ ဒေါင်းလုဒ်သည် Apple ၏ notarization စစ်ဆေးအတည်ပြုမှု မရရှိထားပါ။ README ရှိ ထည့်သွင်းခြင်းညွှန်ကြားချက်များကို လိုက်နာပါ။

06 စက်တင်ဘာ 2026

ဗားရှင်း 1.4

ဘရောက်ဇာနှင့် ထုတ်ဝေမျိုးကွဲ ပိုများစွာမှ ရွေးနိုင်ပြီး Firefox ပရိုဖိုင်များကို ဆက်စပ်မျိုးကွဲအလိုက် အုပ်စုဖွဲ့ထားသည်။

  • Chrome Dev နှင့် Canary၊ Edge Beta၊ Dev နှင့် Canary၊ Brave Beta နှင့် Nightly၊ Vivaldi Snapshot၊ Firefox Developer Edition နှင့် Nightly တို့ကို သီးခြားဘရောက်ဇာရွေးချယ်မှုများအဖြစ် ထည့်ထားသည်။
  • Opera၊ Arc၊ Orion နှင့် Safari Technology Preview အတွက် အက်ပ်အဆင့် ပုံမှန်ဖွင့်ခြင်း ထည့်ထားသည်။
  • သတ်မှတ်နိုင်လျှင် Firefox ပရိုဖိုင်များကို မှတ်တမ်းတင်ထားသော မျိုးကွဲနှင့်အတူ ထားပြီး ပြန်စစ်ချိန်တွင် ယခင်တွေ့ရှိထားသော ထပ်နေသည့်စာရင်းများကို ဖယ်ရှားသည်။ ယုံကြည်ရသော ဆက်စပ်မှုမီတာဒေတာမရှိသည့် ပရိုဖိုင်များသည် ရှိပြီးသား အရန်လုပ်ဆောင်ပုံကို ဆက်သုံးသည်။
  • macOS က ယာယီဖိုင်လမ်းကြောင်းများကို စံပြုပြီးနောက် ငြင်းပယ်ခံရသည့် Firefox ပရိုဖိုင်လမ်းကြောင်းများကို ပြင်ဆင်ထားသည်။
  • ပံ့ပိုးထားသော ဖွင့်နည်းပေါင်းစပ်မှုများကိုသာ ပြသည်။ သီးသန့်ဝင်းဒိုးများသည် ဘရောက်ဇာအဆင့် ရွေးချယ်မှုများအဖြစ် ဆက်ရှိပြီး ပရိုဖိုင်တစ်ခုချင်းအတွက် သီးသန့်မုဒ် မရရှိပါ။

20 ဩဂုတ် 2026

ဗားရှင်း 1.3

DuckDuckGo ကို ဘရောက်ဇာရွေးချယ်မှုအဖြစ် ယခု ရရှိပြီး ပံ့ပိုးထားသော တရားဝင်ဗားရှင်းများတွင် သီးသန့်ရွေးချယ်မှု ပါဝင်သည်။

  • တူညီသော ရွေးချယ်ဝင်းဒိုးမှ ပုံမှန် သို့မဟုတ် သီးသန့် DuckDuckGo ကို ရွေးပါ။
  • သီးသန့်မုဒ်သည် သီးခြားခွဲထားသော ယာယီဒေတာကို သုံးပြီး တိုးချဲ့ပရိုဂရမ် သို့မဟုတ် သုံးစွဲနိုင်မှုခွင့်ပြုချက် မလိုအပ်ပါ။ ပံ့ပိုးထားသော တရားဝင် တိုက်ရိုက်ဒေါင်းလုဒ်ဗားရှင်းများအတွက်သာ ဖြစ်သည်။
