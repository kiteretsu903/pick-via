မျက်နှာပြင်ပုံများတွင် အင်္ဂလိပ်မျက်နှာပြင်ကို ပြထားသည်။

01 / မဖွင့်မီ ရွေးပါ

မှန်ကန်သော ဘရောက်ဇာ။
မှန်ကန်သော ပရိုဖိုင်။

ဝဘ် သို့မဟုတ် အီးမေးလ်လင့်ခ်တစ်ခုစီအတွက် သင့်တော်သော ဦးတည်ရာကို ရွေးပါ။

01

မှန်ကန်သော လင့်ခ်၊ မှန်ကန်သော ပရိုဖိုင်။

ဖွင့်သုံးထားသော ဘရောက်ဇာ သို့မဟုတ် ပရိုဖိုင်၊ သို့မဟုတ် ပံ့ပိုးထားသော ဘရောက်ဇာအဆင့် သီးသန့်ဝင်းဒိုးကို ရွေးပါ။

02

အီးမေးလ်လင့်ခ်၊ မှန်ကန်သော အက်ပ်။

mailto: လင့်ခ်တိုင်းကို တူညီသော မူလအက်ပ်သို့ ပို့မည့်အစား သင်လိုချင်သော မှတ်ပုံတင်ထားသည့် အီးမေးလ်အက်ပ်ကို ရွေးပါ။

03

နှောင့်နှေးမှုမရှိဘဲ ရွေးပါ။

ပုံမှန်ရွေးချယ်မှုများကို အစီအစဉ်ချပြီး တစ်ချက်နှိပ်ခြင်း သို့မဟုတ် ကီးဘုတ်ဖြတ်လမ်းကို သုံးပါ။

04

သင့်ဘရောက်ဇာ မျိုးကွဲလည်း ပါဝင်သည်။

သီးခြား Chrome နှင့် Edge မျိုးကွဲများ၊ Brave Beta သို့မဟုတ် Nightly၊ Vivaldi Snapshot နှင့် Firefox Developer Edition သို့မဟုတ် Nightly ကို ရွေးပါ။ ဆက်စပ်မျိုးကွဲကို သိရှိထားသော Firefox ပရိုဖိုင်များသည် ထိုမျိုးကွဲနှင့်အတူ ရှိနေမည်။

05

ရွေးချယ်စရာ ဘရောက်ဇာများ ပိုများလာသည်။

Opera၊ Arc၊ Orion နှင့် Safari Technology Preview သည် ပုံမှန်ဘရောက်ဇာရွေးချယ်မှုများကို ပေးသည်။ ပရိုဖိုင်နှင့် သီးသန့်ဝင်းဒိုး ပံ့ပိုးမှုသည် ဘရောက်ဇာအလိုက် ကွဲပြားသည်။ ဘရောက်ဇာပံ့ပိုးမှု ကြည့်ရန် →

02 / အီးမေးလ်အက်ပ် ရွေးပါ

အီးမေးလ်လင့်ခ်၊
မှန်ကန်သော အက်ပ်။

macOS သည် ပုံမှန်အားဖြင့် mailto: လင့်ခ်များကို မူလအက်ပ်တစ်ခုသို့ ပို့သည်။ PickVia က သင့် Mac တွင် မှတ်ပုံတင်ထားသော အီးမေးလ်အက်ပ်များမှ အကြိမ်တိုင်း ရွေးချယ်နိုင်စေသည်။

◌
ကိုယ်ရေးအချက်အလက်ကို အခြေခံမှ ကာကွယ်ထားသည်PickVia သည် မူလတောင်းဆိုမှုကို သင့်ရွေးချယ်မှုထံ တိုက်ရိုက်ပို့သည်။ အီးမေးလ်အကြောင်းအရာကို မှတ်တမ်းမတင်သလို မသိမ်းဆည်းပါ။

03 / သင့်ရွေးချယ်မှုများ ပြင်ဆင်ပါ
