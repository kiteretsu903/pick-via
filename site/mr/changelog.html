आवृत्ती 1.5

ॲप आणि वेबसाइट 80 भाषांमध्ये उपलब्ध आहेत, तसेच README चे 12 भाषांमध्ये अनुवाद आहेत. सेटिंग्जमध्ये तुमची भाषा निवडा.

  • सुलभता आणि स्वयंचलन परवानग्यांसह प्रायोगिक Safari Stable प्रोफाइल वापरून पाहा. प्रत्येक लिंक निवडलेल्या प्रोफाइलच्या नवीन विंडोमध्ये उघडते.
  • DuckDuckGo च्या खाजगी सत्रांची पुनर्प्राप्ती आणि साफसफाई सुलभ केली आहे. सँडबॉक्समध्ये न चालणारे सुसंगत 1.203.x बिल्ड खाजगी मोडमध्ये लिंक उघडण्यास समर्थन देतात; सामान्य लिंकसाठी विशिष्ट आवृत्ती किंवा प्रकाशकाच्या स्वाक्षरीची अट नाही.
  • बिल्डसाठी एकच निश्चित Apple Development प्रमाणपत्र वापरले जाते. डाउनलोड नोटराइज केलेले नाही; README मधील इन्स्टॉलेशन सूचनांचे पालन करा.

आवृत्ती 1.4

अधिक ब्राउझर आणि आवृत्ती-प्रकार निवडा; Firefox प्रोफाइल संबंधित आवृत्ती-प्रकारानुसार गटबद्ध आहेत.

  • Chrome Dev आणि Canary; Edge Beta, Dev आणि Canary; Brave Beta आणि Nightly; Vivaldi Snapshot; तसेच Firefox Developer Edition आणि Nightly हे स्वतंत्र ब्राउझर पर्याय जोडले.
  • Opera, Arc, Orion आणि Safari Technology Preview साठी ॲप पातळीवर सामान्य उघडणे जोडले.
  • Firefox प्रोफाइलचा नोंदवलेला आवृत्ती-प्रकार ओळखता आल्यास ती त्याच्याशी जोडून ठेवली जातात आणि पुन्हा शोधताना जुने सापडलेले डुप्लिकेट काढले जातात. विश्वासार्ह संबंध मेटाडेटा नसलेल्या प्रोफाइलसाठी विद्यमान पर्यायी पद्धत कायम राहते.
  • macOS तात्पुरत्या पथांच्या सामान्यीकरणानंतर नाकारले जाणारे Firefox प्रोफाइल पथ दुरुस्त केले.
  • फक्त समर्थित उघडण्याच्या पद्धतींची संयोजने दाखवली जातात. खाजगी विंडो हे ब्राउझर पातळीवरील पर्याय आहेत; विशिष्ट प्रोफाइलसाठी खाजगी मोड उपलब्ध नाही.
