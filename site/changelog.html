What is new
in PickVia.

A concise record of every public PickVia release. Download the latest version from GitHub.

20 AUG 2026Current release

Version 1.3

DuckDuckGo joins PickVia with ordinary and private targets that need no Accessibility permission or browser extension.

  • Discover trusted official DuckDuckGo builds as a standard browser target.
  • Open links through DuckDuckGo or DuckDuckGo Private from the same chooser used by other browsers.
  • Run DuckDuckGo Private in a separate real Fire Window with disposable, PickVia-managed browser state.
  • Keep ordinary DuckDuckGo bookmarks, cookies, autofill, extensions, and preferences isolated from private routing.
  • Bind private delivery, reuse, recovery, quarantine, and cleanup to the exact managed process without Accessibility automation or an extension.

18 AUG 2026

Version 1.2

Google Chrome Beta now works as a separate browser, with its own profiles and normal or private targets.

  • Discover Google Chrome Beta through its official macOS application identity.
  • Keep Beta profiles and profile access separate from stable Google Chrome.
  • Offer browser-default and discovered-profile targets in normal and private modes.
  • Resolve the trusted Chrome Beta executable before launching a selected target.

15 AUG 2026

Version 1.1

Email links now get the same intentional choice as web links, with private, app-level routing for the mail apps already on your Mac.

  • Choose an installed mail app whenever you open a mailto: link.
  • Discover, enable, disable, reorder, and rescan registered mail applications in Mail Settings.
  • Configure mail routing during onboarding, or keep your existing default mail application.
  • Keep recipients, subjects, message bodies, and the original mail request out of the chooser, clipboard, logs, and saved configuration.
  • Preserve browser and mail configuration through rescans, onboarding, Settings sessions, and launch recovery.

14 AUG 2026First public release

Version 1.0

The first public release of PickVia: a native macOS chooser for browser targets, profiles, and supported private modes.

  • Choose a browser target for every HTTP and HTTPS link.
  • Support Safari, Chrome, Chromium, Edge, Brave, Vivaldi, and Firefox.
  • Use discovered Chromium-family and Firefox profiles, plus normal and private targets where supported.
  • Keep the chooser on the current macOS Desktop and prepare it after launch for faster first use.
  • Install with a drag-to-Applications DMG.
