<p align="center"><strong>توقّف عن فتح الروابط في المتصفح أو الملف الشخصي الخطأ.</strong></p>

قد يعيد macOS استخدام نافذة المتصفح أو الملف الشخصي الخطأ، بينما يرسل كل رابط `mailto:`
إلى تطبيق بريد افتراضي واحد ثابت. يسألك PickVia أين تريد فتح كل رابط، لتختار
ملف المتصفح الشخصي أو تطبيق البريد المثبّت الذي تحتاج إليه فعلًا.

**[زر موقع PickVia](https://kiteretsu903.github.io/pick-via/)** للاطّلاع على
لقطات الشاشة وأبرز الإصدارات و[سجل التغييرات](https://kiteretsu903.github.io/pick-via/changelog.html).

## ما الذي يفعله

- **اختيار متصفح أو ملف شخصي لكل رابط ويب.**
- **اختيار تطبيق بريد مثبّت لكل رابط بريد إلكتروني.**
- **معالجة الروابط محليًا دون حفظ سجل للروابط المفتوحة.**

## التثبيت

1. نزّل `PickVia-v1.5.1.dmg` وافتحه من
   [إصدار GitHub](https://github.com/kiteretsu903/pick-via/releases/latest).
2. اسحب **PickVia** إلى مجلد **التطبيقات** الظاهر في أداة التثبيت.
3. افتح **PickVia** من التطبيقات واتّبع خطوات الترحيب.
4. اختر **تعيين كافتراضي**. يطلب macOS إذنًا منفصلًا لمعالجة
   روابط HTTP وHTTPS.
5. يمكنك اختياريًا مراجعة تطبيقات البريد المثبّتة وجعل PickVia
   المعالج الافتراضي لروابط `mailto:`، أو اختيار **تخطّي إعداد البريد**.

### التشغيل الأول وGatekeeper

الإصدار PickVia v1.5.1 موقّع بشهادة Apple Development ولم يخضع للتوثيق لدى Apple. قد يمنع macOS
تشغيل التطبيق المنزّل لأول مرة. إذا نزّلته من إصدار GitHub واخترت الوثوق به:

1. حاول فتح PickVia مرة واحدة وأغلق التحذير.
2. افتح **إعدادات النظام ← الخصوصية والأمن** ومرّر إلى **الأمن**.
3. انقر **فتح على أي حال**، ثم أكّد **فتح**. يتوفر الزر لمدة
   ساعة تقريبًا بعد محاولة التشغيل المحظورة.

إذا لم يتوفر **فتح على أي حال**، فتأكّد من وجود **PickVia.app** في التطبيقات،
وحاول تشغيله مرة واحدة ليظهر الحظر، ثم نفّذ:

```zsh
xattr -dr com.apple.quarantine "/Applications/PickVia.app"
```

تشرح Apple تجاوز Gatekeeper هذا وآثاره الأمنية في
[فتح التطبيقات بأمان على Mac](https://support.apple.com/en-asia/102445).

## دعم المتصفحات

| المتصفح / الإصدارات | الملفات الشخصية | عادي | نافذة خاصة |
|---|---:|---:|---:|
| Safari | تجريبي | نعم | لا |
| Safari Technology Preview | لا | نعم | لا |
| DuckDuckGo | لا | نعم | نعم* |
| Chrome Stable / Beta / Dev / Canary, Chromium | نعم | نعم | نعم |
| Edge Stable / Beta / Dev / Canary | نعم | نعم | نعم |
| Brave Stable / Beta / Nightly | نعم | نعم | نعم |
| Vivaldi Stable / Snapshot | نعم | نعم | نعم |
| Firefox Stable / Developer Edition / Nightly | نعم | نعم | نعم |
| Opera, Arc, Orion | لا | نعم | لا |

\* يستخدم DuckDuckGo الخاص بيانات حالة معزولة ومؤقتة في البُنى المتوافقة غير الخاضعة
للعزل، دون قيد على الإصدار. ولا يتطلب إضافة لـ DuckDuckGo
أو وصولًا إلى تسهيلات الاستخدام. لا تتطلب روابط DuckDuckGo العادية إصدارًا
محددًا أو توقيع ناشر بعينه. تُنظّف بيانات الحالة الخاصة بعد انتهاء عملية
المتصفح أثناء تشغيل PickVia، أو عند تشغيل لاحق أو توجيه رابط لاحق.

يظهر كل إصدار مثبّت كمتصفح منفصل باسمه وأيقونته.
تُستبعَد ملفات Firefox الشخصية المرتبطة بإصدار مثبّت آخر من قائمة الملفات
الشخصية لذلك المتصفح. يتبع الارتباط مسار التطبيق المسجّل لدى Firefox؛
وتحتفظ الملفات الشخصية التي تفتقر إلى بيانات وصفية أو تحتوي على بيانات غير معروفة بالسلوك البديل الحالي،
وقد تظهر ضمن أكثر من إصدار.

تعمل الوجهات الافتراضية على مستوى المتصفح دون الوصول إلى الملفات الشخصية؛ ويضيف منح الوصول
الملفات الشخصية المكتشفة. النوافذ الخاصة خيارات على مستوى المتصفح: ولا يُدعَم الجمع بين
ملف شخصي محدد والوضع الخاص. توفّر Opera وArc وOrion
حاليًا توجيهًا عاديًا على مستوى التطبيق فقط.

يختلف الدعم باختلاف إصدار المتصفح وحالة بدء التشغيل.

## ملفات Safari الشخصية (تجريبي)

فعّل ملفات Safari Stable الشخصية في إعدادات المتصفح. تتطلب هذه الميزة الاختيارية
أذونات تسهيلات الاستخدام (التحكم في الجهاز والوصول إلى البيانات على macOS 27 أو أحدث)
والأتمتة. يُفتح كل رابط في نافذة جديدة ضمن الملف الشخصي المحدد.
يظل توجيه ملفات Safari الشخصية تجريبيًا.

للبناء محليًا، اضبط `PICKVIA_SIGNING_IDENTITY` على بصمة شهادة توقيع الشفرة
لديك، أو احفظها في ملف `.signing-identity` المتجاهَل، ثم شغّل
`scripts/build-app.sh`. استخدم الهوية نفسها عبر عمليات إعادة البناء للحفاظ على هوية
التطبيق لدى أذونات macOS.

## دعم البريد

يتعامل PickVia مع روابط `mailto:` فقط، ويكتشف التطبيقات المثبّتة التي
يسجّلها macOS لروابط البريد الإلكتروني، ويوفّر خيارات على مستوى التطبيق — وليس الحسابات
أو الملفات الشخصية أو الهويات أو أوضاع إنشاء الرسائل. تتيح إعدادات البريد تفعيل المعالجات المسجّلة
وتعطيلها وإعادة ترتيبها وفحصها؛ ويظل إعداد البريد اختياريًا أثناء
الإعداد الأولي.

## الخصوصية

- تُعالج عناوين URL المفتوحة محليًا؛ ولا يرسلها PickVia أو يسجّلها أو يحتفظ بها أبدًا.
- لا يصل PickVia إلى سجل التصفح أو ملفات تعريف الارتباط أو الجلسات أو كلمات السر المحفوظة
  أو محتوى الصفحات.
- لا تعرض نافذة اختيار البريد معاينة للمستلمين أو الموضوعات أو نصوص الرسائل
  أو طلب `mailto:` الأصلي، ولا تسجّلها أو تحتفظ بها.

أزل أذونات الوصول إلى الملفات الشخصية من **إعدادات المتصفح ← الوصول إلى الملفات الشخصية ← إزالة الوصول**.

راجع [سياسة الخصوصية](https://kiteretsu903.github.io/pick-via/privacy.html) كاملةً.
